Privacy Policy

Last updated: October 20, 2026

1. What shorts-agent does

shorts-agent is a private tool used only by the owner of one YouTube channel to upload videos that the owner has personally reviewed and approved to their own channel.

2. Use of YouTube API Services

shorts-agent uses YouTube API Services. By using shorts-agent you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

3. Information we access, collect and use

  • shorts-agent requests only the https://www.googleapis.com/auth/youtube.upload scope, which allows it to upload videos to the authorized channel.
  • It does not read, collect or store any YouTube data such as channel statistics, comments, viewer data, playlists or analytics, and no personal information of any other person.
  • The only stored credential is the OAuth refresh token of the channel owner, used solely to upload the owner's approved videos.

4. How information is stored and shared

The OAuth refresh token is stored as an encrypted secret in the owner's GitHub Actions configuration. No data is sold, shared with third parties or used for advertising. shorts-agent does not use cookies and does not place or read any information on users' devices or browsers.

5. Data deletion and revoking access

  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • When access is revoked, or upon request, the stored refresh token is deleted from the GitHub Actions secrets within 7 days. shorts-agent keeps no other YouTube API data, so nothing else needs to be deleted.
  • shorts-agent does not store YouTube API data for more than 30 days.

6. Contact

Questions about this policy or deletion requests can be sent through the contact options on the owner's YouTube channel.
